# Duboko učenje 1 – Neslužbena rješenja ispitnih zadataka

Ovaj repozitorij sadrži **neslužbena**, detaljno raspisana rješenja ispitnih zadataka iz predmeta **Duboko učenje 1** (*Fakultet elektrotehnike i računarstva, Sveučilište u Zagrebu*). 

Zadaci riješeni u ovoj skripti preuzeti su s javno dostupnih [neslužbenih stranica predmeta](https://www.zemris.fer.hr/predmeti/du1/) ili su rekonstruirani prema dobrom pamćenju kolega :)

## Neke upute
